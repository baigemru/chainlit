# Быстрый поиск

## Что оставляем как есть

- Общий дизайн и структуру главной страницы сохраняем.
- Блок «Быстрый поиск» остаётся на том же месте и выглядит так же.
- Механику запуска поиска не меняем:
  - пользователь нажимает на плашку;
  - система просит фотографию или описание;
  - пользователь отправляет данные;
  - запускается поиск;
  - после завершения открывается результат.
- Плашку «Описать товар» пока не меняем.
- Фильтры над выдачей пока сохраняем в текущем виде.

## Что меняем на главной

В блоке «Быстрый поиск» переименовываем плашку:

**Было:** «Снять товар»  
**Станет:** «Найти по фото»

Других изменений в блоке на этом этапе не делаем.

## Стоимость поиска

Один быстрый поиск теперь стоит **5 кредитов**.

За 5 кредитов пользователь получает:

- 20 найденных карточек;
- варианты товаров (SKU) из этих карточек;
- все карточки расположены в правой части и содержат:
  - крупные изображения товаров;
  - краткую основную информацию о товаре и выбранном SKU (пару строк);
  - краткую основную информацию о продавце (пару строк);
  - кнопки с призывом к действию.

Стоимость должна быть видна до запуска поиска. После запуска не должно возникать ощущения, что пользователь заплатил только за список маленьких ссылок.

## Поиск состоит из двух частей

### 1. Запуск поиска

Эту часть не меняем. Система, как и сейчас, запрашивает фотографию или описание, принимает запрос и запускает поиск.

### 2. Результат поиска

Эту часть меняем полностью.

После завершения поиска экран остаётся разделённым на две части:

- слева — диалог с ПандаПоиском;
- справа — визуальная выдача из 20 найденных карточек, SKU и тд. Сейчас это выглядит как вкладки, можно ли сверху написать коротко, что здесь 20 товаров, подгрузить еще 20 товаров по этому же запросу за 2 кредита?

## Что остаётся в диалоговой части

После завершения поиска в диалоге достаточно короткого сообщения:

> Нашёл 20 карточек. Результаты открыты справа.

При необходимости ниже можно одной строкой показать, как система поняла запрос. Например:

> Искал силиконовый ночник в форме капибары с USB и тёплым светом.

После сообщения оставляем только две кнопки:

1. **Давай я разберу выдачу**
2. **Собрать шорт-лист**
3. **Свой вопрос**

Все остальные кнопки из текущей выдачи убираем, чтобы диалог не выглядел как набор несвязанных предложений.

В частности, здесь больше не нужны:

- «Открыть карточки 1688»;
- большая плашка «Глазами байера»;
- «Да, разбери»;
- «Шорт-лист поставщиков»;
- «Свой вопрос»;
- «Нет, спасибо»;
- «Расширить линейку»;
- повторная кнопка «Снять товар».

Поле ввода внизу остаётся. Пользователь по-прежнему может написать уточнение своими словами.

## Как должна выглядеть правая часть

Сейчас карточки слишком маленькие и выглядят как короткие строки. Возвращаем формат из прошлой версии: большие горизонтальные карточки, в которых фотография является заметной частью карточки, а информация разделена на товар и продавца.

Заголовок панели:

**Результаты поиска — 20 карточек**

### Общий вид карточки товара

```text
┌───────────────────────────────────────────────────────────────────────┐
│                                                                       │
│   БОЛЬШОЕ ФОТО      Название товара                                   │
│                     Цена (юани / рубли), MOQ                          │
│                     Продавец                                          │
│                     Фабрика или посредник                             │
│                     Стаж на 1688, рейтинг                             │
│                                                                       │
│   [Подробнее] [Все варианты] [Ассортимент этого продавца - 2 кредита] │
│   [Ссылка на 1688]                                                    │
└───────────────────────────────────────────────────────────────────────┘
```

Фото должно быть крупным, примерно квадратным и занимать заметную часть карточки. По фотографии пользователь должен сразу понимать, тот ли это товар и какой именно вариант показан.

### Общий вид вариантов (SKU)

```text
┌───────────────────────────────────────────────────────────────────────┐
│                                                                       │
│   БОЛЬШОЕ ФОТО      Название товара                                   │
│                     Цена (юани / рубли), MOQ                          │
│                     Остатки                                           │
│                     Объем                                             │
│                     Вес                                               │
│                                                                       │
│   [Подробнее] [Запросить отзыв - 1 кредит]                            │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

Фото должно быть крупным, примерно квадратным и занимать заметную часть карточки. По фотографии пользователь должен сразу понимать, тот ли это товар и какой именно вариант показан.

## Поведение результата

- После завершения поиска правая панель открывается автоматически.
- По умолчанию показываются все 20 карточек и SKU (варианты).
- Когда нажимаешь на кнопку "Подробнее" должна появиться дополнительная вкладка со всей инфо от 1688 по этой карточки и SKU (важна именно связка всего), пользователя должно автоматом перенести на эту вкладку
- Пользователь прокручивает карточки внутри правой панели, не теряя диалог слева.
- Уточнение в диалоге может обновить или отфильтровать текущую выдачу, но не должно автоматически запускать новый платный поиск.
- Если требуется новый поиск и новое списание 5 кредитов, система сначала прямо об этом сообщает.
