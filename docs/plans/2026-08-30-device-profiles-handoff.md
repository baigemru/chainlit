## 2. Что осталось сделать

### 2.1. Дозавершить браузерную проверку (прервана)

На :8000, мобильный пресет 375px:

1. Клик по селектору профилей в шапке → в списке ровно три: «Панда»,
   «Быстрый поиск по фото», «Быстрый поиск по описанию». Никаких pc.
2. Клик «📷 Снять товар · 1 кредит» → открывается «Быстрый поиск по фото»,
   в ленте НЕТ реплики-призрака от стартера, приходит приветствие профиля.
3. Кнопка нового чата → открывается снова «Панда» (сброс на дефолт), а не
   последний выбранный профиль.
4. `http://localhost:8000/?device=pc` на мобильной ширине → набор становится
   десктопным («Бамбуковый хаб» + 4 мастера); оверрайд переживает
   SPA-переходы (sessionStorage).

Десктопный пресет:

5. Дефолт — «Бамбуковый хаб», его стартеры, в селекторе 5 профилей, никаких
   mobile.
6. `?device=mobile` на десктопе → мобильный набор (это же QA-механизм).

Кросс-устройство (ключевое требование владельца «старые треды без
ограничений» — на демо без персистентности проверяется суррогатно):

7. На десктопной ширине выбрать «Поиск по картинке», отправить сообщение,
   переключить пресет на мобильный, перезагрузить: профиль треда должен
   резолвиться (селектор не должен молча перекинуть на первый профиль).
   Полноценно это проверяется на panda с БД — см. 2.4.

Всё, что найдено сломанным, — чинить в тех же файлах и перепрогонять
vitest + type-check (не забывая: правки react-client требуют его пересборки
